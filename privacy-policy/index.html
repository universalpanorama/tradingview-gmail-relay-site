Privacy policy

Effective date: 12 October 2026

TradingView Gmail Relay is a private-use application being developed to identify TradingView trading alerts received in a designated Gmail account and route validated signals to a separate trading service. This policy describes its intended data handling. Features described as planned may not yet be active.

Information accessed

With the account holder's permission, the application requests the Google Gmail API https://www.googleapis.com/auth/gmail.metadata scope. This permits access to email metadata, including message identifiers, sender, subject, labels and other headers. It does not permit reading message bodies or attachments. The application is intended to process only messages relevant to TradingView alerts, although it may need to inspect metadata of other messages to identify them.

Purpose and use

Relevant alert metadata may be parsed into trading signal fields such as instrument, action, order identifier, timestamp and event identifier. These details are intended to support validation, duplicate detection, execution controls, diagnostics and trading-state reconciliation. No Gmail information is used for advertising or sold.

Services involved

The planned workflow uses Google's Gmail API to access metadata; Railway to host signal-processing code; Airtable to record trading state or event information; and Bitget to execute authorised spot orders. These providers may process relevant data according to their own terms and policies. This informational website is hosted separately on Netlify.

Storage and retention

OAuth credentials and tokens are intended to be held as protected service configuration, not embedded in this public website or committed to source control. The application may retain parsed alert fields, message identifiers, processing results and trading-state records where necessary for operations and audit. Specific retention periods and deletion procedures are not yet finalised; these will be documented before the application is used for unattended live trading.

Sharing and security

Gmail data is intended to be shared only with the services necessary for this private trading workflow, not with advertisers or data brokers. Access is intended to be limited to the authorised account and configured service credentials. No system can be guaranteed completely secure; operational safeguards are being tested before live deployment.

Control and revocation

The account holder can revoke Gmail access in their Google Account's third-party connections settings. Revoking access stops future authorised Gmail API access, but does not automatically erase records already stored in other services. Deletion of stored operational records can be requested through the project contact below.

Google API Services User Data Policy

Use of information received from Google APIs is intended to adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact

For privacy questions or requests concerning this project, contact mitch1137small@gmail.com.

This policy will be updated if the implementation, retention arrangements or data recipients change.
